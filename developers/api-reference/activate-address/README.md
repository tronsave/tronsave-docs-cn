# 激活地址

新的 TRON 地址在被**激活**之前并不存在于链上：在此之前它无法接收资源委托，向它的首笔转账也会更贵。生成大量充值地址的交易所、支付服务商和发薪工具通常需要批量激活这些地址。

TronSave 的地址激活 API 提供两项功能：

| 接口 | 作用 | 认证 | 费用 |
| --- | --- | --- | --- |
| [检查地址](check-addresses.md) | 一次报告最多 100 个地址的状态：已激活、合约地址或无效地址 | 无需 | 免费 |
| [激活地址](activate-addresses.md) | 一次请求激活最多 100 个地址 | `apikey` | **每个需要激活的地址 1.5 TRX**，从你的内部账户扣除 |

已激活的地址会被跳过，不收取费用。请求被接受后，激活会异步完成；可再次调用**检查地址**进行确认。

## 开始之前

* 获取 API 密钥并为内部账户充值——请参阅 [身份验证](../../authentication.md)。
* 内部账户中需保留至少 `1.5 × 未激活地址数量` 的 TRX。

{% hint style="info" %}
还需要为大量地址提供能量？请参阅 [快速充值](../fast-charge/README.md)。在网站上，**批量购买（Bulk Buy）**工具也可以在为收款地址提供资源之前激活其中未激活的地址（每个约 1.1 TRX）。
{% endhint %}
